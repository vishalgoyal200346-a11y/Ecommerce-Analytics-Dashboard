# E-commerce Analytics Dashboard

## Project Overview
An interactive E-commerce Analytics Dashboard built using Microsoft Power BI to analyze Indian online retail orders, revenue, product categories, cities, and payment methods.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX

## Dataset
- 1,500 order records
- Indian cities and states
- Product categories and order dates
- Revenue, discounts, and payment methods

## Key Performance Indicators
- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value (AOV)

## Dashboard Insights
- Monthly revenue trends
- Category-wise revenue
- City-wise order analysis
- Payment method distribution
- Interactive date and category slicers

## Purpose
This project demonstrates data visualization, KPI reporting, and interactive business analysis using Power BI.
